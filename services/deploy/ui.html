建立私网与连接 VPS

先验证主机身份，密码仅用于当前连接，15 分钟空闲后释放连接。

全新 VPS 尚未安装 Tailscale？

在厂商控制台由管理员安装 Python 3 与 Tailscale，在官方页面完成两端登录，再回到此处填写私网地址。

apt-get update
apt-get install -y python3 ca-certificates curl
curl -fsSL https://tailscale.com/install.sh -o /tmp/tailscale-install.sh
# 在管理员终端先检查脚本内容与来源，再执行：
sh /tmp/tailscale-install.sh
tailscale up

这段是首次引导交接，不会从本页面自动执行。已有设备不要反复初始化。

账号授权与交接

普通用户可自动创建；第三方注册、订阅、登录、验证码和条款由本人完成。

注册前：指纹浏览器 → VPS 代理出口 → Claude 官方网站

  1. 在指纹浏览器的独立配置中设置已准备的 VPS 代理。本人核实实际出口为预期 VPS 出口，并检查是否有请求绕过代理；连接异常时先停止注册/登录。
  2. 在这份配置中直接打开 https://claude.ai/，由本人完成注册、登录、验证码和条款，保持同一配置和 VPS 出口。
  3. VPS 普通用户执行账号添加后，将本次官方授权链接私下打开在上述浏览器配置中；如果自动打开了默认浏览器，先关闭那个页面。完成授权后回到原来的 VPS 登录流程，再启动一次 Claude 验证。

VPS 代理与浏览器配置需要事先准备，当前助手不自动创建或检测。Tailscale、Orca 配对、SSH 连接与浏览器代理分别核实；浏览器代理不会自动应用于安装助手。不要在计划或 Agent 对话中填写代理密码、授权链接或验证码。

Orca 配对与常驻服务

首次完成前台配对后再交接服务；已有正式服务会复用，避免中断当前任务。

在 Windows Orca 的 Settings → Remote Orca Servers 中添加服务器。配对链接作为密码处理，不粘贴到 Agent 对话。

Git 加强模式
