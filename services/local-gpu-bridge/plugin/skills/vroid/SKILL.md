---
name: vroid
description: Create and edit local VRoid Studio characters through the project-scoped vroid-local MCP tools, inspect model previews, save .vroid projects and export VRM avatars.
---

Use vroid-local, not shell or raw TCP. Start with vroid_tools and local_projects. The managed Studio instance starts on first operation; its first bootstrap can take several minutes. Network isolation must be ready.

Do not confuse editor startup with model readiness. A successful state reply has editor_connected=true. phase=awaiting_model, in_edit=false and model_ready=false mean Studio is already running at the model selection screen: call create or open immediately, according to the user's intended character. Waiting cannot open a model. phase=loading_model/updating_model means a character operation is in progress; phase=editing means it is ready. status only describes the command queue. Never start a two-minute background wait just because there is no open character.

Use vroid_operation with an enabled project_id, operation and arguments. Workflow: state, create(gender) or open(path), categories(section), presets/enter(section,category), select_preset or set_param, camera, screenshot, save(path). Section/category names are case-sensitive; discover exact labels instead of guessing. Numeric/color parameter paths come from enter and are not filesystem paths. Model previews are inline MCP images without the editor UI.

open/save require project-relative .vroid paths; save always needs path and replace=true if the file exists. Keep the original model unless replacement was intended. Save before main_menu, which requires explicit discard_changes=true. Destination directories must already exist. Download saved project files with download_project_file. Development sync uses Git only; do not add a second upload path.

Mutation calls block while the model rebuilds. A timeout can mean the operation is still running: query status before repeating. Never poll screenshot during rebuilds. Do not query host identity, hardware or network information. No batch, UI screenshot, shell, raw protocol or diagnostic bypass is available.

Toolkit 1.6 adds export_vrm through its Studio extension. Call vroid_operation(export_vrm) with {path: project-relative .vrm, format: "1.0" (default) or "0.0", title: model title, author: artist name, replace?:boolean}. The folder must exist; overwriting requires replace=true. This invokes Studio native export, waits for the completed file and returns to editing without a file dialog. Save the .vroid separately to preserve editable source. Bridge 1.6.3 defaults to license_preset=commercial_modifiable: commercial use, modification and redistribution allowed, attribution required. VRM 1.0 permissions or VRM 0.x CC_BY metadata are applied before the receipt. Use license_preset=restrictive to opt out. Existing .vrm files can use set_vrm_license(path,replace=true,license_preset?). Fresh title/author omit local contact details; preserve source asset license obligations. Fetch the .vrm with download_project_file or import it directly using Blender import_asset. If the local Studio extension is missing, run scripts/install-vroid-export.py on the PC, not on the VPS. Do not ask the user to manually export when the installed export_vrm is available. Local rendering is on the PC; do not install another VRoid Studio on the VPS.

Blender VRM support: check blender_operation(scene_info). Its capabilities.vrm_import/vrm_export indicate installed operator support, including in the factory-startup managed instance. Use import_asset/export_asset with project-relative .vrm paths, or Blender Python. Preserve the model metadata/license requirements. This is separate from exporting the initial .vrm from VRoid Studio; never ask to reinstall VRoid MCP as a substitute for the Blender VRM extension.

Compatibility: if the session rejects export_vrm with "Invalid option for operation" but vroid_tools lists it, use operation=save with the exact same .vrm path/title/author/format/replace arguments. This is an alias of the native exporter, not a .vroid source save. Do not report that the plugin lacks export or ask the user to click export manually. The host may have cached an old operation enum; /reload-plugins also refreshes it. The current server allowlist is always returned by vroid_tools.
